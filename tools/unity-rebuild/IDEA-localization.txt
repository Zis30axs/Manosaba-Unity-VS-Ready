IDEA 修改中文剧本 → Unity Play 模式

试玩时运行配置：同步中文剧本并构建 Unity 试玩资源
位置：.idea/runConfigurations/Sync_Localization_Build.xml
备用配置：仅同步中文剧本到 Unity（不重建，不能保证 Play 模式读到新文本）

操作
1. 在 IDEA 修改并保存 res/Assets/#WitchTrials/Localization/zh-Hans/Text 下的 .txt。
   第一章第一幕开头：Scripts/Act01_Chapter01/Act01_Chapter01_Adv01.txt
2. 运行“同步中文剧本并构建 Unity 试玩资源”。
3. Unity 已打开时：切回 Unity，让新 Editor 脚本导入；若正在播放，停止 Play。
   WAITING_FOR_EDIT_MODE 表示等待停止播放。不会强制停止你正在进行的游戏。
4. 等待运行窗口显示 [BUILD] OK、进程退出码为 0。
5. 在 Unity 打开 Assets/Scenes/Boot.unity，进入新的 Play 模式，选择简体中文。
   从第一章第一幕开头开始；测试句含：
   【IDEA 同步测试：新的开场文本已生效】
   从中途存档继续可能跳过这句话。

同步内容与构建
- 同步整个 zh-Hans/Text 目录，当前 444 个 .txt；保留 Unity 目标 .meta/GUID。
- 原文注释（以 ; 开头）、文本 ID（以 # 开头）和脚本路径不要改。
- 这是中文文本编辑入口，不负责新增剧情命令、重建分支或注册新资源。
- 不依赖 Python 插件或仓库旧虚拟环境；IDEA 使用已安装的 Shell Script 插件运行 PowerShell。
- 使用 Windows 系统默认 PowerShell 路径；非标准 Windows 安装需要调整 Interpreter。
- Unity 未打开：使用 common.ps1 查找 Editor，批处理重建当前 Addressables 设置。
- Unity 已打开：固定的 Library/ManosabaLocalization/request.json 请求由 Editor 脚本处理。
- 请求只允许固定重建操作，不携带待执行命令或目标路径。
- 即使 changed=0 也会重建，修复“已经复制，但资源包还旧”的情况。
- 不会重新导入所有游戏资源或重新套用旧 Addressables 分组计划。
- 本入口不更新外部游戏 exe。

命令行备用入口（在仓库根目录运行）
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/unity-rebuild/sync_localization_idea.ps1
仅复制：在上述命令末尾加 -SyncOnly。
